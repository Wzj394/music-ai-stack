# 04 · 人声与歌声

> 合成人声、转换音色、克隆声音。
> ⚠️ **这一类技术涉及法律和伦理，先看第一节。**
> **核实时间：2026-10-12**

---

## ⚠️ 先说清楚：这件事有底线

声音克隆技术已经非常成熟，几秒钟素材就能模仿一个人的声音。

### 绝对不要做的

| 行为 | 为什么 |
|---|---|
| **克隆他人声音，未经本人同意** | 可能违法（多国已有专门立法） |
| **伪造某人说了他没说过的话** | 这是欺诈 |
| **用他人声音做商业发布** | 侵犯声音权益 |
| **把 AI 生成的人声伪装成真人演唱发布** | 欺骗听众，平台会封号 |

### 可以做的

- 克隆**自己的**声音
- 用**明确授权**的声音素材
- 学习研究、本地实验
- 明确标注「AI 生成」的作品

> **自检**：这段音频发出去，当事人看到会不会被冒犯？会，就别发。

**另外**：发布 AI 翻唱前先查平台规定。多数平台要求标注 AI 生成。

---

## 四类任务分清楚

| 任务 | 缩写 | 做什么 | 典型用途 |
|---|---|---|---|
| **歌声合成** | SVS | 给歌词+曲谱 → 唱出来 | 虚拟歌手、demo 试唱 |
| **语音合成** | TTS | 给文字 → 说出来 | 配音、有声书、旁白 |
| **声音转换** | SVC / VC | 一段人声 → 换成另一个音色 | 翻唱、修音色 |
| **歌声转录** | — | 唱 → MIDI | 扒旋律 |

**最容易混的是 SVC 和 SVS**：

- **SVS**：你告诉它"唱什么"，它从零合成
- **SVC**：你给它一段**已经唱好的**人声，它只换音色，保留原来的唱法和表情

**对做音乐的人来说 SVC 更实用** —— 你自己唱一版，然后转成想要的声音。

## 一、歌声合成（SVS）

| 名称 | 用途 | 链接 | 状态 | 备注 |
|---|---|---|---|---|
| **DiffSinger** | 扩散式歌声合成（中文生态最活跃） | [openvpi/DiffSinger](https://github.com/openvpi/DiffSinger) | 🟢 2026-09 | ⚠️ **社区主维护在 openvpi**；原仓 [MoonInTheRiver/DiffSinger](https://github.com/MoonInTheRiver/DiffSinger) |
| **OpenUtau** | SVS 编辑器 / 引擎宿主 | [stakira/OpenUtau](https://github.com/stakira/OpenUtau) | 🟢 2026-10 | MIT；**有图形界面，新手入口**；连接 DiffSinger / NNSVS 等引擎 |
| **SoulX-Singer** | **零样本**高保真歌声合成 | [Soul-AILab/SoulX-Singer](https://github.com/Soul-AILab/SoulX-Singer) | 🟢 2026-05 | Apache-2.0；**不训练直接换音色唱歌** |
| **NNSVS** | 神经歌声合成工具链 | [nnsvs/nnsvs](https://github.com/nnsvs/nnsvs) | 🟡 2023-10 | MIT；日语生态为主 |
| **Amphion** | TTS / SVS / VC 一体研究工具包 | [open-mmlab/Amphion](https://github.com/open-mmlab/Amphion) | 🟢 2026-03 | MIT |

**主流**：中文翻唱用 **OpenUtau + DiffSinger 生态**；要零样本换音色唱新歌用 **SoulX-Singer**。

**坑**：SVS 难点在**数据标注**（音素时长、音高曲线、呼吸），自训声库工程量远超预期。

|---|---|---|---|---|---|
| **GPT-SoVITS** | 少样本中文语音克隆（1 分钟素材） | [RVC-Boss/GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS) | 🟢 2026-10 | ✅ MIT | **中文效果与文档最好，训练门槛低** |
| **IndexTTS / IndexTTS-2** | 中文零样本 TTS + 情感/时长控制 | [index-tts/index-tts](https://github.com/index-tts/index-tts) | 🟢 2026-09 | — | 中文韵律好 |
| **CosyVoice 2 / 3** | 多语零样本 TTS + 指令控制 | [FunAudioLLM/CosyVoice](https://github.com/FunAudioLLM/CosyVoice) | 🟢 2026-05 | ✅ Apache-2.0 | |
| **Fish Speech** | 多语 TTS 与声音克隆 | [fishaudio/fish-speech](https://github.com/fishaudio/fish-speech) | 🟢 2026-10 | ❌ CC-BY-NC-SA-4.0 | 权重非商用 |
| **F5-TTS** | 流匹配零样本 TTS | [SWivid/F5-TTS](https://github.com/SWivid/F5-TTS) | 🟢 2026-10 | ❌ 权重 CC-BY-NC-4.0 | 代码 MIT |
| **Kokoro** | 82M 小模型高质量 TTS | [hexgrad/kokoro](https://github.com/hexgrad/kokoro) | 🟡 2025-08 | ✅ Apache-2.0 | 英文最佳，中文一般；**CPU 可实时** |
| **Piper** | 端侧实时 TTS | [OHF-Voice/piper1-gpl](https://github.com/OHF-Voice/piper1-gpl) | 🟢 2026-10 | ⚠️ GPL-3.0 | 注意新仓名 |
| **VibeVoice** | 长对话多说话人 TTS | [microsoft/VibeVoice](https://github.com/microsoft/VibeVoice) | 🟢 2026-10 | ✅ 权重 MIT | |
| **Qwen3-TTS** | 阿里 Qwen 系 TTS | [QwenLM/Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS) | 🟢 2026-03 | 未核实 | |
| **Coqui TTS / XTTS-v2** | 老牌 TTS 框架 | 原仓 🔴 / [idiap fork](https://github.com/idiap/coqui-ai-TTS) 🟢 2026-10 | | 原仓 CPML 非商用 | **新项目用 idiap fork** |

> 另有 Higgs Audio v2、Orpheus、Dia、Zonos、CSM 等 2025-2026 各家模型，**多以英文为主，中文项目不建议首选**。

**主流**：中文生产用 **GPT-SoVITS**（少样本克隆）或 IndexTTS-2 / CosyVoice（零样本 + 可控）；英文轻量部署用 Kokoro / Piper；端侧统一走 `sherpa-onnx`。

**坑**：

- ⚠️ **很多「开源」TTS 只是代码开源、权重是非商用**（Fish、F5、XTTS 都是）
- **中文多音字与韵律靠前端文本规范化，模型救不了**
- 克隆相似度随参考音频质量剧烈波动，**30 秒干净素材胜过 10 分钟嘈杂素材**

## 三、声音转换 / 音色克隆（SVC / VC）

| 名称 | 用途 | 链接 | 状态 | 备注 |
|---|---|---|---|---|
| **RVC** | 实时/离线声音转换，社区生态最大 | [RVC-Project/Retrieval-based-Voice-Conversion-WebUI](https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI) | 🟢 2026-08 | MIT；10 分钟素材可训，**翻唱事实标准** |
| **Applio** | RVC 的现代化 fork | [IAHispano/Applio](https://github.com/IAHispano/Applio) | 🟢 2026-10 | 界面与训练流程比原版好用 |
| **so-vits-svc** | 早期歌声转换标杆 | [svc-develop-team/so-vits-svc](https://github.com/svc-develop-team/so-vits-svc) | 🔴 **已归档 2023-10** | ⚠️ **已被取代，但旧教程满天飞** |
| **Seed-VC** | 零样本语音/歌声转换 | [Plachtaa/seed-vc](https://github.com/Plachtaa/seed-vc) | 🔴 **已归档 2025-04** | 权重可用但不再修 bug |
| **DDSP-SVC** | 轻量实时 SVC | [yxlllc/DDSP-SVC](https://github.com/yxlllc/DDSP-SVC) | 🟢 | 训练快、显存低；音质上限较低 |
| **kNN-VC** | 零样本 VC 研究基线 | [bshall/knn-vc](https://github.com/bshall/knn-vc) | 🟢 2026-01 | **无需训练** |
| **OpenVoice v2** | 零样本音色克隆 + 风格控制 | [myshell-ai/OpenVoice](https://github.com/myshell-ai/OpenVoice) | 🟡 2025-04 | 权重许可需确认 |

**主流**：翻唱/配音用 **RVC 或 Applio**；零样本不训练用 kNN-VC。

**坑**：

- ⚠️ **so-vits-svc 已归档两年多，但教程仍满天飞**，照着做会浪费大量时间
- 训练素材必须**先去伴奏、去混响**，分离质量直接决定转换质量
- 实时转换需要低延迟声卡与 ASIO

## 新手从哪开始

```
"我想让 AI 唱我的歌"
   → OpenUtau（图形界面，先玩玩看）
   → 再考虑 DiffSinger，或零样本的 SoulX-Singer

"我想把自己的声音变成别的音色"
   → RVC 或 Applio（最成熟，WebUI 好上手）
   → 注意：素材必须是你自己的或已授权的

"我需要配音/旁白"
   → 中文：GPT-SoVITS / IndexTTS-2 / CosyVoice
   → 英文轻量：Kokoro / Piper

"我想克隆某个音色"
   → GPT-SoVITS（少样本能力强）
   → 但先回去读第一节
```

## 坑清单

| 坑 | 说明 |
|---|---|
| **素材质量决定上限** | 带混响、带伴奏、带噪声的素材，训出来一定糊 |
| **过拟合** | 训练步数太多，模型只会"背"训练素材 |
| **音域问题** | 男声模型唱女声的调会崩 |
| **齿音和气息** | 齿音、呼吸声处理常不自然，需要后期修 |
| **源分离残留** | 用分离出来的人声训模型，会把 artifacts 一起学进去 |
| **中文声调** | SVS 对中文四声的处理是难点，多试几个引擎 |
| **许可证** | 代码开源 ≠ 权重可用 |

---

## 法律与伦理再强调

- 训练/使用他人声音前，**拿到明确授权**
- 发布时**标注 AI 生成**
- 不要生成任何可能被误认为真实的、涉及他人的音频
- 留意当地法律变化（声音权、人格权相关立法在快速推进）

> 技术门槛已经降到几乎为零，**所以判断力才是真正的门槛**。
