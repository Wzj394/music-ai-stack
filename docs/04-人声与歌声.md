# 04 · 人声与歌声

> 合成人声、转换音色、克隆声音。
> ⚠️ **这一类技术涉及法律和伦理，先看第一节。**

---

## ⚠️ 先说清楚：这件事有底线

声音克隆和音色转换技术已经非常成熟，几秒钟素材就能模仿一个人的声音。这意味着：

### 绝对不要做的

| 行为 | 为什么 |
|---|---|
| **克隆他人声音，未经本人同意** | 可能违法（多个国家和地区已有专门立法） |
| **伪造某人说了他没说过的话** | 这是欺诈 |
| **用他人声音做商业发布** | 侵犯声音权益 |
| **把 AI 生成的人声伪装成真人演唱发布** | 欺骗听众，平台会封号 |

### 可以做的

- 克隆**自己的**声音
- 用**明确授权**的声音素材（比如买了版权的音源库）
- 学习研究、本地实验
- 明确标注「AI 生成」的作品

> **一个简单的自检**：如果这段音频发出去，当事人看到会不会觉得被冒犯？
> 会，就别发。

**另外**：发布 AI 翻唱类内容前，先查你所在平台的规定。多数平台要求标注 AI 生成，且对未授权翻唱会下架处理。

## 三类任务分清楚

| 任务 | 英文缩写 | 做什么 | 典型用途 |
|---|---|---|---|
| **歌声合成** | SVS | 给歌词+曲谱 → 唱出来 | 虚拟歌手、demo 试唱 |
| **语音合成** | TTS | 给文字 → 说出来 | 配音、有声书、旁白 |
| **声音转换** | SVC / VC | 一段人声 → 换成另一个音色 | 翻唱、修音色 |
| **声音克隆** | — | 少量素材 → 模仿某人说话/唱 | ⚠️ 高风险，见上 |

**最容易混的是 SVC 和 SVS**：

- **SVS**：你告诉它"唱什么"（音高、歌词），它从零合成
- **SVC**：你给它一段**已经唱好的**人声，它只换音色，保留原来的唱法和表情

对做音乐的人来说，**SVC 更实用** —— 你自己唱一版，然后转成想要的声音。

## 实际情况

### SVC 已经很成熟了

RVC 出来之后，声音转换基本是"人人可用"的状态：

- **素材要求低**：几分钟干净人声就能训
- **有 WebUI**：不写代码能用
- **推理速度快**：消费级显卡实时都没问题

**所以门槛不在技术，在**：素材从哪来、有没有授权。

### TTS 已经卷到"难分真假"

最新的 TTS 模型，短句子的自然度已经很难和真人区分。这带来的影响：

- 好消息：配音、有声书成本大幅下降
- 坏消息：诈骗电话、虚假音频的门槛也降到零

**对你来说**：做音乐的话，TTS 主要用在旁白、人声采样、念白段落。

### SVS 反而最尴尬

歌声合成听起来简单（有谱子照着唱就行），实际上最难：

- 要控制音高、时值、咬字、气声、颤音
- 要跨语种（中文的声调、日文的音节）
- 要"有感情"

结果就是：**能唱，但常常有塑料感**。做 demo 够用，做成品还差点意思。

## 新手从哪开始

```
看你想干嘛：

"我想让 AI 唱我的歌"
   → OpenUtau（图形界面，先玩玩看）
   → 再考虑 DiffSinger

"我想把自己的声音变成别的音色"
   → RVC（最成熟，WebUI 好上手）
   → 注意：素材必须是你自己的或已授权的

"我需要配音/旁白"
   → Edge-TTS（免费、快，先用它试试够不够）
   → 不够再上 CosyVoice / IndexTTS

"我想克隆某个音色"
   → GPT-SoVITS（少样本能力强）
   → 但先回去读第一节
```

## 坑清单

| 坑 | 说明 |
|---|---|
| **素材质量决定上限** | 带混响、带伴奏、带噪声的素材，训出来的模型一定糊 |
| **过拟合** | 训练步数太多，模型只会"背"训练素材，新内容就不像了 |
| **音域问题** | 男声模型唱女声的调，会崩 |
| **齿音和气息** | 模型的 s / sh / 呼吸声处理常常不自然，需要后期修 |
| **源分离的残留** | 用分离出来的人声训模型，会把分离 artifacts 一起学进去 |
| **中文声调** | SVS 对中文四声的处理是难点，多试几个引擎 |
| **显卡显存** | 训练比推理吃显存得多，注意模型给的推荐配置 |

## 法律与伦理再强调一次

这个领域的工具本身是中性的，**用它做什么才是问题**。

- 训练/使用他人声音前，**拿到明确授权**
- 发布时**标注 AI 生成**
- 不要生成任何可能被误认为真实的、涉及他人的音频
- 留意当地法律变化（声音权、人格权相关立法在快速推进）

> 技术门槛已经降到几乎为零，**所以判断力才是真正的门槛**。
