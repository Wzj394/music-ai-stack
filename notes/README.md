# 实践笔记

这里放**自己动手做过**的记录。不是摘抄文档，是"我踩了什么坑、最后怎么解决的"。

## 为什么单独放一个目录

看过的教程三天就忘，自己折腾到凌晨两点才跑通的东西，一年后还记得。

而且 —— 笔记是写给**三个月后的自己**看的。那时候你已经忘了当时的上下文，所以：

- 写「为什么这么做」，不只是「怎么做」
- 把报错信息**原样贴进去**（以后搜得到）
- 记下当时的环境（版本号、显卡、系统）

## 命名规则

```
YYYY-MM-DD-主题.md
```

例子：

```
2026-10-12-demucs分离人声初体验.md
2026-10-15-reaper跑python脚本踩坑.md
2026-10-20-whisper转写中文歌词.md
```

日期放前面，天然按时间排序。

## 写什么

**值得写的**：

- 折腾超过 20 分钟才解决的问题
- 工具之间的配合方式（A 的输出怎么喂给 B）
- 参数怎么调、调到多少、为什么
- 性能数字（多久跑完、占多少显存）
- 让你「原来是这样」的瞬间

**不用写的**：

- 官方文档里有的基础概念
- 一次就成功的简单操作
- 还没验证过的猜测（那是 `docs/` 的草稿，不是笔记）
